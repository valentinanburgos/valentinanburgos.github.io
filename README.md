# Career & Leadership Portfolio

A responsive, single-page personal portfolio built with HTML, CSS, and vanilla JavaScript. Designed for GitHub Pages.

## Before publishing

1. In `index.html`, replace `YOUR_EMAIL@example.com` with your professional email.
2. Replace the LinkedIn link (`https://www.linkedin.com/`) with your personal profile URL.
3. Optional: add a PDF résumé at `assets/resume.pdf`. If you don't add it, remove or update the résumé link in `index.html`.
4. Verify all dates, award names, role titles, and descriptions.
5. Add your name to the browser title, footer, and site branding if desired.

## Publish using GitHub Pages

1. Sign in to [GitHub](https://github.com/).
2. Create a new repository. For the simplest personal site URL, name it `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username). A public repository works with GitHub Pages on GitHub Free.
3. Upload `index.html`, `styles.css`, `script.js`, this README, and the `assets` folder to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to finish publishing. Your site should appear at `https://YOUR-USERNAME.github.io/`.

If you choose a repository name other than `YOUR-USERNAME.github.io`, the site URL will usually be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Local preview

Open `index.html` in a browser to preview the site. For the closest match to GitHub Pages, use a simple local server or the editor preview.

## Privacy

Only publish contact details and documents you are comfortable making public. Avoid uploading confidential lab data, private student information, or documents that contain personal information you do not want indexed.
